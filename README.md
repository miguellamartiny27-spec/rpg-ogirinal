# RPG Original

RPG 2D de mundo aberto em pixel art, com universo original e combate por turnos.

## Versão atual: 0.1

- Tela inicial com botão para começar
- Primeira região explorável: Clareira do Começo
- Mapa de grama, trilha, lago, árvores e pedras
- Personagem controlável em quatro direções
- Câmera acompanhando o jogador
- Colisões com obstáculos
- Teclas WASD e setas no computador
- Direcional na tela para celular

## Tecnologias

- Phaser 3
- JavaScript
- Vite

## Rodar localmente

```bash
npm install
npm run dev
```

## Publicação

O projeto tem um workflow do GitHub Actions para gerar a versão web. Em **Settings → Pages**, selecione **GitHub Actions** como fonte de publicação.
