# RPG Original

RPG 2D de mundo aberto em pixel art, com universo original e combate por turnos.

## Stack
- Phaser 3
- JavaScript
- Vite

## Desenvolvimento
O projeto começa como experiência single-player para navegador e dispositivos móveis. Multiplayer fica para uma etapa futura.

## Rodar localmente
```bash
npm install
npm run dev
```
